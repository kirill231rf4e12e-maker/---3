# 📝 The Blog

Учебное **web-приложение для ведения блога**, реализующее регистрацию и авторизацию пользователей, создание и управление публикациями, подписки, теги, комментарии, публичные и приватные посты, а также персональную ленту на основе подписок.

> 💡 **Важно:** ниже представлено подробное описание реализованного функционала с примерами работы приложения. Это позволяет ознакомиться с возможностями проекта непосредственно через README.

---

## 🚀 Запуск проекта

Для запуска приложения необходимо:

1. Создать базу данных с названием `the_blog`.
2. Импортировать структуру и исходные данные из файла `bd.sql`.
3. Запустить приложение.
4. Авторизоваться с помощью одного из тестовых аккаунтов или зарегистрировать нового пользователя.

# 📌 Функционал приложения

## 1. Регистрация и авторизация

Пользователь может зарегистрировать новый аккаунт или войти в систему, используя существующие учетные данные.

После успешной авторизации становятся доступны основные возможности приложения:

* создание и управление публикациями;
* подписка на других пользователей;
* просмотр лент;
* добавление комментариев;
* работа с персональным контентом.

## 2. Создание поста

Авторизованный пользователь может создать собственную публикацию, указав заголовок, содержание и необходимые теги.

<img width="800" alt="Форма создания поста" src="https://github.com/user-attachments/assets/eafdbeb9-623b-4fab-8d6f-926a78650bac" />

После успешного создания **публичный пост** становится доступен другим пользователям и отображается в соответствующих лентах.

### 🔒 Приватные публикации

Для создания приватного поста необходимо установить соответствующий чекбокс.

После публикации система автоматически генерирует **уникальный код доступа**, который используется для просмотра скрытого поста.

<img width="800" alt="Код доступа к приватному посту" src="https://github.com/user-attachments/assets/8b639272-48d4-4811-901f-994546f6bef2" />

## 3. Лента подписок

Пользователь может подписываться на других авторов и формировать собственную персональную ленту.

В ленте подписок отображаются публикации пользователей, на которых выполнена подписка. Это позволяет быстро получать новые публикации интересующих авторов.

<img width="850" alt="Лента подписок" src="https://github.com/user-attachments/assets/ce692dff-34c0-4593-a3bf-27221e60d37d" />

---

## 4. Публичная лента

Публичная лента содержит публикации других пользователей, доступные для общего просмотра.

Просматривать публичные посты можно независимо от наличия подписки на автора. При необходимости пользователь также может подписаться на понравившегося автора непосредственно из ленты.

<img width="850" alt="Публичная лента" src="https://github.com/user-attachments/assets/0a0a0e04-c9a2-4aee-823f-b1d0dfd61844" />

---

## 5. Просмотр поста

Для просмотра полной публикации необходимо нажать кнопку **«Открыть»** в соответствующей ленте.

На странице поста отображается его полное содержимое, информация об авторе и комментарии пользователей.

<img width="850" alt="Просмотр поста" src="https://github.com/user-attachments/assets/972f706b-9698-4acb-b751-24259afaa2f9" />
