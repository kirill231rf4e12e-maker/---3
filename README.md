
Учебное web-приложение для блога с регистрацией и авторизацией, созданием, редактированием и удалением постов, подписками, тегами и комментариями. Реализованы публичные и скрытые публикации, а также персональная лента на основе подписок.

Запуск проекта

Для запуска приложения необходимо:

1. Создать базу данных с названием `the_blog`.
2. Импортировать структуру и данные из файла `bd.sql`.
3. Запустить приложение.
4. Авторизоваться с помощью одного из тестовых аккаунтов или зарегистрировать нового пользователя.

1. Регистрация и авторизация

Пользователь может зарегистрировать новый аккаунт или войти в систему, используя существующие учетные данные.

После успешной авторизации становятся доступны основные возможности приложения: создание и управление публикациями, подписка на пользователей, комментирование постов и персональная лента.

## 2. Создание поста

Авторизованный пользователь может создать собственную публикацию, указав заголовок, содержание и необходимые теги.

<img width="800" alt="Форма создания поста" src="https://github.com/user-attachments/assets/eafdbeb9-623b-4fab-8d6f-926a78650bac" />

После успешного создания **публичный пост** становится доступен в лентах других пользователей.

Для создания **приватного поста** необходимо установить соответствующий чекбокс. После публикации система автоматически генерирует уникальный код доступа, который используется для просмотра скрытой публикации.
