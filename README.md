# 📝 The Blog

> Учебное **web-приложение для ведения блога** с регистрацией и авторизацией пользователей, созданием и управлением публикациями, подписками, тегами и комментариями.

Приложение поддерживает **публичные и приватные публикации**, персональную ленту на основе подписок, поиск постов по тегам и просмотр профилей авторов.

> 💡 **Примечание:** в данном README подробно представлен весь реализованный функционал с наглядными примерами работы приложения.

---

# 🚀 Запуск проекта

Для запуска приложения необходимо выполнить следующие шаги:

1. Создать базу данных с названием `the_blog`.
2. Импортировать структуру и исходные данные из файла `bd.sql`.
3. Запустить приложение.
4. Авторизоваться с помощью тестового аккаунта или зарегистрировать нового пользователя.

# 📌 Функционал приложения

## 1. 🔐 Регистрация и авторизация

Пользователь может **зарегистрировать новый аккаунт** или войти в систему, используя существующие учетные данные.

После успешной авторизации становятся доступны основные возможности приложения:

* ✍️ создание и управление публикациями;
* 👥 подписка на других пользователей;
* 📰 просмотр лент;
* 💬 добавление комментариев;
* 👤 просмотр профилей авторов;
* 🏷️ работа с тегами;
* 🔒 работа с приватными публикациями.

## 2. ✍️ Создание поста

Авторизованный пользователь может создать собственную публикацию, указав:

* заголовок;
* содержание поста;
* необходимые теги;
* тип публикации.

<img width="800" alt="Форма создания поста" src="https://github.com/user-attachments/assets/eafdbeb9-623b-4fab-8d6f-926a78650bac" />

После успешного создания **публичный пост** становится доступен другим пользователям и отображается в соответствующих лентах.

### 🔒 Приватные публикации

Для создания приватного поста необходимо установить соответствующий чекбокс.

После публикации система автоматически генерирует **уникальный код доступа**, который используется для просмотра скрытой публикации.

<img width="800" alt="Код доступа к приватному посту" src="https://github.com/user-attachments/assets/8b639272-48d4-4811-901f-994546f6bef2" />

## 3. 📰 Лента подписок

Пользователь может **подписываться на других авторов** и формировать собственную персональную ленту.

В ленте подписок отображаются публикации пользователей, на которых выполнена подписка. Это позволяет быстро отслеживать новые публикации интересующих авторов.

<img width="850" alt="Лента подписок" src="https://github.com/user-attachments/assets/ce692dff-34c0-4593-a3bf-27221e60d37d" />

---

## 4. 🌎 Публичная лента

Публичная лента содержит публикации других пользователей, доступные для общего просмотра.

Просматривать публичные посты можно **независимо от наличия подписки на автора**.

При необходимости пользователь может сразу из ленты перейти к профилю автора и **подписаться на него**.

<img width="850" alt="Публичная лента" src="https://github.com/user-attachments/assets/0a0a0e04-c9a2-4aee-823f-b1d0dfd61844" />

## 5. 📖 Просмотр поста

Для просмотра полной публикации необходимо нажать кнопку **«Открыть»** в соответствующей ленте.

На странице поста отображаются:

* полное содержимое публикации;
* информация об авторе;
* комментарии пользователей;
* возможность оставить собственный комментарий.

## 7. 🏷️ Поиск по тегам и 🔒 доступ к приватным постам

В нижней части публичной ленты расположен дополнительный функционал для поиска публикаций и открытия приватного контента.

### 🏷️ Поиск по тегам

Пользователь может указать интересующий **тег** и получить список соответствующих публикаций.

При поиске отображаются только **публичные посты**, соответствующие выбранному тегу.

Пользователь может перейти в профиль автора любой публикации.

В профиле отображаются **публичные посты пользователя**, а также доступна возможность **подписаться или отписаться от автора**.
