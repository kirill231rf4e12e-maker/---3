# ---3
Web-приложение для блога с регистрацией и авторизацией, созданием, редактированием и удалением постов, подписками, тегами и комментариями. Реализованы публичные и скрытые публикации, а также персональная лента. Подробное описание функционала и анализ задачи представлены в README для удобства.
